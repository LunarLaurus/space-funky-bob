SNES Address Conversion

PC Offset → SNES: If offset < 0x400000: Add 0x800000, else add 0xC00000
SNES → PC Offset: Subtract 0x800000 (or 0xC00000), then use LoROM mapping

LoROM Address Formula

File Offset = ((Bank - 0x80) * 0x8000) + Offset
Where: SNES Address = (Bank << 16) | Offset

Tileset Format

SNES 4bpp Graphics

Each tile is 8x8 pixels at 4 bits per pixel (16 colors per tile):

Bytes per tile: 8 × 8 × 0.5 = 32 bytes
Tiles per 8KB block: 8192 / 32 = 256 tiles
Total tilesets: 12+ identified blocks

Bitplane Layout (LSB first)

Plane 0: bytes 0-7   (bit 0 of each pixel)
Plane 1: bytes 8-15  (bit 1)
Plane 2: bytes 16-23 (bit 2)
Plane 3: bytes 24-31 (bit 3)

Pixel(x,y) = ((plane0[y] >> x) & 1) 
           | (((plane1[y] >> x) & 1) << 1) 
           | (((plane2[y] >> x) & 1) << 2) 
           | (((plane3[y] >> x) & 1) << 3)

Compression

LZ77 Variant Detected

  • Type: Custom 8-bit LZ77
  • Header: Byte flags + length/offset pairs
  • Literals: Copied directly when bit is clear
  • Back-references: When bit is set, copy from history buffer

Decompression Algorithm

function decompress(data, max_size):
    output = []
    i = 0
    while len(output) < max_size and i < len(data):
        flags = data[i++]
        for bit in 0..7:
            if len(output) >= max_size: break
            
            if flags & (1 << bit):
                # Back-reference
                length_byte = data[i++]
                offset = ((length_byte & 0xF0) << 4) | data[i++]
                length = (length_byte & 0x0F) + 3
                
                for j in range(length):
                    output.append(output[-offset])
            else:
                # Literal
                output.append(data[i++])
    
    return bytes(output)

Level Categories & World Structure

Important: The game has 3 main worlds, not 8 separate worlds. Lava, Ultra, and Bubble are level categories that exist WITHIN the 3 main worlds, NOT as separate worlds. Level types (borglevel, buglevel, ancientlevel, lavalevel, ultralevel, bubblelevel, borglevel2, borglevel3) are distributed across the 3 game worlds as defined in the INITLEVE.A themapsequence tables.

World 0: Borg/Bug Factory (14 levels)

  • Theme: Industrial/Robotic
  • ROM Offset: 0xD4000
  • Tileset: 0x008000 (borgblocks), 0x008800 (bugblocks)
  • Level Types: borglevel (0), buglevel (1)
  • Music: borgtheme (3), bugtheme (4)
  • Sequence: 0,1,2,9,4,22,6,5,14,20,21,18,13,11

The first world introduces players to the Borg collective. Industrial factory settings with robotic enemies including guards, shooters, jumpers, and various flying variants. Boss encounters include Snake Boss, Tank Boss, and Flower Boss.

World 1: Ancient/Borg2/Lava (19 levels)

  • Theme: Ruins/Industrial/Volcanic (mixed)
  • ROM Offset: 0xE4000
  • Tileset: 0x009000 (ancientblocks), 0x009800 (borgblocks2), 0x00A000 (lavablocks)
  • Level Types: ancientlevel (4), borglevel2 (2), lavalevel (6)
  • Music: anctheme (5) - Shared between Ancient and Lava, bugtheme (4)
  • Sequence: 23,15,7,24,16,51,19,29,32,55,25,3,27,28,33,30,26,40,34

The second world features a mix of ancient temple ruins, borg factory continuation, and volcanic lava areas. Lava levels share the Ancient music theme (anctheme). Boss encounters include Queen Boss, Ancient Boss, Pod Boss, and Lava Boss.

World 2: Ultra/Bubble/Borg3 (17 levels)

  • Theme: Sci-fi/Jungle/Industrial (mixed)
  • ROM Offset: 0xF4000
  • Tileset: 0x00A800 (ultrablocks), 0x00B000 (bubblocks), 0x00B800 (borgblocks3)
  • Level Types: ultralevel (8), bubblelevel (9), borglevel3 (3)
  • Music: ultratheme (6), bugtheme (4) - Shared between Bug and Bubble
  • Sequence: 35,48,36,38,43,53,47,44,37,49,56,52,12,50,10,54,59

The third and final world presents Ultra Force sci-fi environments, bubble forest/jungle areas, and final borg factory levels. Bubble levels share the Bug music theme (bugtheme). Boss encounters include Ultra Boss, Mutoid Boss, Pussman Boss, Virus Boss, and Screen Lifter.

  7. Pointer Analysis - Traced level data pointers from ROM code
