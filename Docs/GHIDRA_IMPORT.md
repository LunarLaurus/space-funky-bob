# Ghidra Import Instructions for B.O.B. ROM Map

## Overview
These instructions guide you through importing the B.O.B. ROM analysis results into Ghidra for efficient reverse engineering.

## Prerequisites
- Ghidra 10.x or later
- `rom_map.json` generated by `bob_map.py`
- B.O.B. ROM file

## Step 1: Import the ROM into Ghidra

1. Launch Ghidra and create a new project (or open existing)
2. File → Import File → Select your ROM file
3. When prompted for format:
   - Language: **65816:LE:16:default**
   - Base Address: **0x808000** (for LoROM mapping)
   - If HiROM: use **0xC00000**
4. Click OK to import

## Step 2: Apply ROM Map Annotations (Manual Method)

### Using Bookmarks
1. Open the ROM in CodeBrowser
2. Window → Bookmarks
3. For each region in `rom_map.json`:
   - Click "Add Bookmark" (+ icon)
   - Address: Convert region `start` address to Ghidra format (e.g., 0x1000 → 808000:1000)
   - Category: Use region `type` (code/compressed/data/graphics_candidate)
   - Description: `[type] size=0xXXXX confidence=XX%`

### Using Memory Blocks
1. Window → Memory Map
2. For key regions (especially compressed blocks):
   - Click "Add Block" (+ icon)
   - Block Name: e.g., "COMPRESSED_0x1234"
   - Start Address: region start (in Ghidra addressing)
   - Length: region size
   - Permissions: Set based on type (code=RWX, data=RW)

## Step 3: Apply ROM Map Annotations (Script Method)

Create a Ghidra Python script `ImportBOBMap.py`:

```python
# ImportBOBMap.py - Import B.O.B. ROM map into Ghidra
# Place in: <Ghidra>/scripts/ or project scripts folder
# Run via: Window -> Script Manager

import json
from ghidra.program.model.symbol import SourceType
from ghidra.program.model.address import AddressSet

# Prompt for rom_map.json file
rom_map_file = askFile("Select rom_map.json", "Open")

# Load JSON
with open(rom_map_file.getAbsolutePath(), 'r') as f:
    data = json.loads(f.read())

mapping = data.get("rom_mapping", "LoROM")
header_offset = data.get("header_offset", 0)

# Address translation for LoROM: ROM offset -> SNES address
# LoROM: ROM 0x0000-0x7FFF maps to SNES $8000-$FFFF (bank 0)
# LoROM: ROM 0x8000-0xFFFF maps to SNES $8000-$FFFF (bank 1), etc.
def rom_to_snes_lorom(rom_offset):
    bank = (rom_offset // 0x8000)
    offset_in_bank = rom_offset % 0x8000
    snes_addr = (bank << 16) | (0x8000 + offset_in_bank)
    return snes_addr

# Base address (should match import settings)
base = 0x808000 if mapping == "LoROM" else 0xC00000

# Create bookmarks for each region
bookmark_mgr = currentProgram.getBookmarkManager()
regions = data.get("regions", [])

print("Importing {} regions...".format(len(regions)))

for i, region in enumerate(regions):
    region_type = region["type"]
    start_offset = region["start"] - header_offset
    size = region["size"]
    confidence = region["confidence"]
    
    # Convert to Ghidra address
    if mapping == "LoROM":
        snes_addr = rom_to_snes_lorom(start_offset)
    else:
        snes_addr = start_offset  # Simplified for HiROM
    
    try:
        addr = currentProgram.getAddressFactory().getAddress(hex(snes_addr))
        
        # Create bookmark
        description = "{} | size={} | confidence={}%".format(
            region_type, 
            region["size_hex"], 
            confidence
        )
        
        bookmark_mgr.setBookmark(
            addr,
            "Analysis",
            region_type.upper(),
            description
        )
        
        # For code regions, disassemble
        if region_type == "code" and confidence > 70:
            # Create address set for this region
            addr_set = AddressSet(addr, addr.add(min(size-1, 0xFFFF)))
            disassemble(addr)
        
        if i % 100 == 0:
            print("Processed {} regions...".format(i))
            
    except Exception as e:
        print("Error processing region at {}: {}".format(hex(start_offset), str(e)))

print("Import complete! Check Window -> Bookmarks")
```

## Step 4: Load Decompressed Graphics

For compressed blocks that were successfully decompressed:

1. Window → Defined Data
2. For each decompressed file:
   - Find the corresponding ROM offset
   - Right-click address → Data → Create Array
   - Set data type based on content (usually `byte`)
   - Length: decompressed size

## Step 5: Analyze Code Regions

1. Navigate to code regions (check bookmarks with type="code")
2. Analysis → Auto Analyze (if not already done)
3. Enable these analyzers:
   - **ASCII Strings**
   - **Data Reference**
   - **Function Start Search**
   - **Non-Returning Functions**
   - **Subroutine References**
4. Let Ghidra analyze (may take several minutes)

## Step 6: Verify with Visualization

Open `rom_map.html` in a browser alongside Ghidra to:
- Quickly identify region types
- Cross-reference addresses
- Verify analysis coverage

## Useful Ghidra Tips

### Navigation
- **G**: Go to address
- **Ctrl+F**: Search memory
- **Alt+Left/Right**: Navigate back/forward

### Labeling
- **L**: Create label at cursor
- **;**: Add end-of-line comment
- **Ctrl+Shift+G**: Find all references

### Analysis
- **D**: Create data at cursor
- **F**: Create function at cursor
- **Ctrl+L**: Rename selected item

## Thresholds Used in Analysis

| Metric | Threshold | Interpretation |
|--------|-----------|----------------|
| Opcode density | >85% | Likely code |
| Entropy | <6.5 | Code or structured data |
| Entropy | >7.2 | Compressed/encrypted |
| Entropy | <4.0 | Graphics or repetitive |

## Troubleshooting

**Issue**: Addresses don't match
- **Solution**: Verify base address matches ROM mapping (LoROM=0x808000, HiROM=0xC00000)

**Issue**: Script fails to run
- **Solution**: Check Ghidra Python version, verify JSON file path

**Issue**: Code regions not disassembling
- **Solution**: Manually disassemble with 'D' key, check if region is actually code
